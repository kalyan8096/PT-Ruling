What is PT_Ruling?

PT_Ruling is a standalone Windows desktop application designed to automate end-to-end performance testing workflows, Selenium browser recording, dynamic JMeter (.jmx) script generation, live resource monitoring, and automated Word/Chart report generation.

Built as a native, self-contained executable, PT_Ruling eliminates complex Python environment setups while providing built-in checks for Java (JRE/JDK), Microsoft Visual C++ Redistributable, and Apache JMeter 5.6.3.

What can I do with it?

🎥 Smart Browser Recording

Capture real user workflows via integrated Selenium WebDriver automation and convert traffic directly into structured test scenarios.

⚙️ Automated JMX Engine

Dynamically construct, parse, and execute Apache JMeter XML (.jmx) test plans without manual XML editing.

📊 Live Monitoring & Chaos

Track active execution, real-time system health metrics, and simulate chaos scenarios from a unified live activity registry.

📄 Executive Reporting

Automatically calculate statistical percentiles, plot Matplotlib charts, and export ready-to-share Microsoft Word (.docx) reports and email summaries.

System Requirements & Auto-Checks

PT_Ruling includes built-in environment validation on startup:

  • Operating System: Windows 10 or Windows 11 (64-bit).
  • Java Runtime: JRE or JDK 8+ installed and available in system PATH (Required for JMeter execution).
  • VC++ Runtime: Microsoft Visual C++ 2015–2022 Redistributable (x64).
  • Apache JMeter: Automatically detects or configures portable Apache JMeter 5.6.3 inside your local tools directory.

Verify File Integrity (Antivirus & SmartScreen Note)

Because PT_Ruling is packed with encrypted bytecode protection to safeguard intellectual property, Windows SmartScreen may display an "Unknown Publisher" prompt on first launch. Click More Info → Run Anyway to launch the suite.

You can verify the integrity of your downloaded executable in Windows Command Prompt using:

certutil -hashfile PT_Ruling.exe SHA256
